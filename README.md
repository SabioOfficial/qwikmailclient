# QwikMailClient

---

QwikMailClient is, well, a web-based mail client! It is supposed to be very quick to navigate, lightweight and most importantly, funcitonal! 

## Features

* Gmail Integration
* Starring emails
* Sending messages
* Seeing inbox emails
* Seeing sent emails
* Light, dark mode
* Privacy settings
* and more!

## How do I locally host this?

A .env.example is provided for your convenience. Use that in reference to create your own .env file.
